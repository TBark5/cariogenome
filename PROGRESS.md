# PROGRESS

## Done
- **Phase 0 — Setup:** `.venv` (Python 3.14), pinned `requirements.txt`, git repo,
  `config.yaml`, `HYPOTHESIS.md` (committed before any analysis), `DECISIONS.md`, shared
  plotting style `src/cariogenome/plotting.py`.
- **Phase 1 — M1:** 22 RefSeq genomes (cache `data/raw/`, git-ignored), RBH orthologs of
  14 coding genes + 16S, QC (284/286 pass), `results/m1_catalog.csv`, `ACCESSIONS.md`,
  committed per-gene cache `data/genes/` + `data/genbank/`. SYNTHETIC fallback in
  `synthetic.py`.
- **Phase 2 — M2:** composition (GC, GC3, GC skew, CAI, RSCU, amino acids) with
  gene-level tests.
- **Phase 3 — M3:** identity matrices, center-star MSAs, codon alignments, entropy
  conservation, extreme regions, GH70 family alignment.
- **Phase 4 — M4:** NJ/UPGMA trees with 100 bootstraps (split-based), concatenated
  housekeeping reference tree, RF and conflict-based discordance.
- **Phase 5 — M5:** pooled NG86 dN/dS with codon bootstrap, saturation check, sliding
  windows, per-gene vs controls, per-species replication, synthetic recovery validation
  (`validation.py`).
- **Phase 6 — M6/M7:** GH70 motifs, PWMs, logos, catalytic-residue ranks; PDB 3AIE
  conservation mapping, distance correlation, Ramachandran, interactive py3Dmol HTML.
- **Phase 7 — Visuals:** 27 PNG figures at 300 dpi + 1 HTML, Okabe-Ito palette,
  `figures/CAPTIONS.md` (generated by `captions.py`), synthesis forest plot.
- **Phase 8 — App:** `app.py` Streamlit dashboard (8 tabs, gene selector); verified with
  AppTest and a live server; screenshots in `docs/screenshots/`.
- **Phase 9 — Quality:** 30 pytest tests (all pass); `run_all.py` (about 160 s); a clean
  clone with a fresh venv reproduced every results file byte for byte (except runtimes).
  SYNTHETIC mode verified end to end, including the dashboard.
- **Phase 10 — Docs:** README, RESULTS_DISCUSSION, METHODS, INTERVIEW_PREP,
  RESUME_BULLETS, LINKEDIN_POST, MORNING_REPORT.

## How to run
```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run_all.py            # everything, about 3 min (downloads once)
.venv\Scripts\python run_all.py --offline  # from committed cache, no network
.venv\Scripts\python -m pytest             # 30 tests, about 30 s
.venv\Scripts\streamlit run app.py         # dashboard
```

## Key files

- `run_all.py`: the pipeline order (M1 → M2 → M3 → M4 → M5 → validation → M6 → M7 →
  summary → captions).
- `src/cariogenome/`: `m1_retrieval.py`, `m1_qc.py`, `m2_composition.py`,
  `m3_conservation.py`, `m4_phylogeny.py`, `m5_selection.py`, `m6_motifs.py`,
  `m7_structure.py` (+ `*_figures.py`), shared `alignment.py`, `phylo.py`, `dnds.py`,
  `codon.py`, `homology.py`, `stats.py`, `seqio.py`, `synthetic.py`, `validation.py`.
- `results/summary_effect_sizes.csv`: every class comparison in one table.
